## 🌟 项目简介

**洛曦智剪（LX SmartClip）** 是作者利用业余时间开发的一套本地化 AI 剪辑实验项目。

旨在探索：在保护用户隐私、不依赖昂贵云端算力的前提下，利用本地多模态模型（ASR + VLM + Embedding + LLM）辅助创作者自动化完成长短视频的粗剪、文案匹配、智能配音字幕生成与剪辑工程联动。

---

## 🚀 核心剪辑功能与架构

### 1. 镜头切片与多模态解析
* **双模式切片**：优先使用 `PySceneDetect` 进行画面镜头转场检测，保留完整镜头；长镜头自动以固定时长兜底切割，避免画面断裂。
* **语音与视觉打标**：
  * **Whisper ASR**：高精度语音转写、台词时间戳提取与人声停顿识别。
  * **VLM 视觉理解**：多模态大模型逐镜头解析人物、动作、场景与景别属性。
* **向量化入库**：生成多维 Embedding 索引，支持海量素材毫秒级召回。

### 2. 双剪辑模式与三级匹配（人工可控兜底）
* **模式一：文案三级精准匹配（`/match`）**
  1. **向量粗筛**：根据分句文案语义召回 TOP12 候选切片；
  2. **LLM 精排**：大模型结合上下文语境推荐最优镜头；
  3. **人工自由兜底**：前端完整保留所有备选片段，支持**一键无缝替换**，彻底解决画面与文案脱节问题。
* **模式二：一键成片与 Agent 编排（`/studio`）**
  * **分层设计**：文案管剧情，向量管镜头；
  * **Agent 对话**：一句话下发剪辑需求，AI 自动规划节奏、转场与 BGM；
  * **专业非编联动**：自动生成配音字幕，并**一键导出剪映草稿工程（Draft）**供二次精修。

## 🛠️ 快速启动

### 1. 启动后端 (FastAPI)
```bash
# 激活 Python 虚拟环境并安装依赖
pip install -r backend/requirements.txt

# 启动后端服务 (端口 18006)
python -m uvicorn app.main:app --host 127.0.0.1 --port 18006
```

### 2. 启动前端 (Next.js 14)
```bash
cd frontend
npm install
npm run dev
```
浏览器访问 `http://localhost:3000` 即可进入系统。
