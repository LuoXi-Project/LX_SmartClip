# 抖音带货口播成片套路

面向 30-60 秒带货口播成片，目标是完播率与转化。

## 文案结构（黄金公式）

1. **黄金 3 秒开场**：冲突 / 提问 / 反常识，禁止品牌自我介绍开场。
   - 好的开场：「别再买 XX 了」「这个方法我后悔没早知道」「月薪 3 千也能 XX」
   - 差的开场：「大家好，今天给大家介绍一款产品」
2. **痛点共鸣（3-10s）**：说出目标用户的具体困扰，越具体越戳人。
3. **卖点证明（10-35s）**：2-3 个卖点，每个卖点 = 一句话结论 + 一个画面证据。卖点之间用快切分隔，不拖沓。
4. **促单收尾（35-60s）**：紧迫感（限时/限量）+ 明确行动指令（点击小黄车/评论区）。

## 剪辑参数建议

- 节奏：fast_cut；单镜头 1.2-2.5 秒，卖点段不超 3 秒一切
- 字幕：弹出式大字，关键词高亮黄色，字号偏大（移动端小屏可读）
- BGM：电子/卡点类，音量 duck 到 -18dB 左右，人声绝对主导
- 转场：硬切为主，卖点切换可用 whip pan 或 zoom punch

## 生成方案时的注意

- mode 选 voiceover（口播驱动）
- target_duration_sec 按文案长度定，不要强行拉长
- 每个卖点段落配一个「证据画面」（产品特写/使用前后对比），没有素材时宁可短也不要空镜头凑数
