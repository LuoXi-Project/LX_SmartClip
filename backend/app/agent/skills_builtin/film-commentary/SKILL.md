# 影视解说节奏

面向 1-5 分钟影视解说/混剪成片，目标是叙事张力与信息密度。

## 叙事结构

1. **悬念钩子（0-5s）**：直接放最冲突的画面 + 一句悬念解说，不要铺垫背景。
2. **分层推进**：按「事件 → 转折 → 升级 → 收束」分层，每层一个信息增量，删掉一切不推动叙事的内容。
3. **留白呼吸**：高强度画面 8-12 秒后接 1-2 秒空镜/静帧 + 音乐过渡，避免疲劳。
4. **收尾回扣**：结尾画面或解说回扣开头悬念，形成闭环。

## 解说词密度

- 语速按 4-4.5 字/秒估算配音时长
- 解说不塞满：画面本身会说话的地方留 1-2 秒纯画面 + BGM
- 每句解说 ≤ 20 字，长句拆短；口语化，删书面词

## 剪辑参数建议

- mode 选 voiceover（解说驱动）
- 节奏 medium：单镜头 2-5 秒；冲突高潮段可加快到 1.5-2.5 秒
- BGM 跟情绪走：铺垫段落轻、高潮段落满，避免全程一个力度
- 转场：dissolve 为主（电影感），高潮段硬切
- 字幕：底部居中、常规大小、不用弹出大字（与带货风区分）

## 混剪特别注意

- 同一部影片的素材注意色调/年代连贯，跳跃过大时用黑场或标题卡过渡
- 盘点类成片用「标题卡 + 编号」分段，每段 15-25 秒
