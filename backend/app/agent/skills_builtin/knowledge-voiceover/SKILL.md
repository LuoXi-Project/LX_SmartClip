# 知识区口播

面向 1-3 分钟知识科普/教程成片，目标是讲清楚 + 记得住。

## 文案结构（总分总变体）

1. **抛问题开场（0-5s）**：用一个问题或反常识结论开场。「为什么 XX？」「你以为 XX，其实不然」
2. **先给结论**：开门见山给核心答案，再展开解释——知识区观众没有耐心等铺垫。
3. **分点展开（每点一个钩子）**：2-4 个要点，每个要点开头一句小结句（方便记笔记），随后 1-2 句展开 + 画面演示。
4. **总结回顾 + 行动指令**：一句话串起全部要点，引导关注/收藏。

## 节奏与画面

- mode 选 voiceover；节奏 medium，单镜头 2-4 秒
- 画面跟随「演示原则」：讲到什么给什么——说数据给数字大字卡，说步骤给步骤演示画面，说对比给分屏
- 每个要点之间可插入 0.5-1 秒标题卡（要点关键词），强化结构感
- 抽象概念没有实拍素材时，宁可放相关空镜 + 大字关键词，不放无关画面

## 字幕与 BGM

- 字幕：常规样式、逐句显示、关键词可加色（不抢画面）
- BGM：轻音乐/lo-fi 类，音量明显低于口播（duck -20dB），不抢讲解
- 知识区忌讳：高能电子乐 + 快闪字幕（观感廉价且干扰理解）
