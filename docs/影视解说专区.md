# 影视解说专区（一键成片）

## 入口

- 前端：**智能剪辑** → 工作区 **「影视解说」**（`/match`，`matchMode=film_commentary`）
- 兼容：`/film` 自动跳转到上述工作区
- API：`/api/film/jobs`

## 流水线（与 `AI影视剪辑方案.md` 对齐）

| 阶段 | 状态 | 说明 |
|------|------|------|
| L1 | `parsing` | 复用 `process`：切片 → ASR →（精准）VLM → Embedding |
| L2–L3 | `scripting` | 单切片摘要 → 六段故事线 → 分句解说文案 |
| L4 | `aligning` | 分句向量匹配 + 时序单调约束 |
| L5 | `planning` | 编译为 `auto_edit` Plan |
| 出片 | `rendering` | TTS + 字幕烧录（`auto_render=true` 时） |

## 模式

- **precise**：`skip_steps` 不含 vlm，多模态向量对齐
- **lightweight**：`skip_steps` 含 `vlm`，ASR + LLM 通识补全摘要

## 使用步骤

1. 素材库上传完整原片
2. 打开 **智能剪辑** → 工作区 **影视解说** → 上方勾选原片 → **开始一键成片**
3. 任务完成后可预览成片，或 **载入方案卡片** 在下方继续精修 / 导出剪映草稿
