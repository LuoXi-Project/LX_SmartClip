# 一、最终产品定位（最精准）
**本地轻量化AI智能素材匹配剪辑工具**
支持：批量素材入库 → 多模式切分 → 多模态理解 → 范围检索 → 三级精准匹配 → 人工兜底 → TTS配音 → 导出剪辑工程文件
**全程本地、可插拔拓展、小白易用、专业可用**

# 二、核心技术栈（100%可插拔抽象）
## 后端
- 框架：**FastAPI**
- 视频处理：FFmpeg + **PySceneDetect**
- 切分模式：**镜头切分 / 固定时长切分（开关可选）**
- ASR：抽象层 → Whisper / 可后续换 OpenAI Whisper API / 讯飞
- VLM：**OpenAI 标准协议抽象层** → 可换 GPT-4V / Qwen-VL / MiniCPM-V 等
- TTS：**抽象层** → edge-tts / 后续换 OpenAI TTS / 火山 TTS
- RAG：**LlamaIndex**（全抽象，可换向量库）
- 向量存储：**SQLite + sqlite-vss**（轻量、可移植、支持任意维度）
- 数据库：**SQLite（元数据+向量一体）**
- 配置：**动态配置文件 + 前端配置页修改**

## 前端
- 框架：**Next.js (React)**
- UI：TailwindCSS + shadcn/ui
- 核心体验：
  - 素材勾选检索
  - **三级匹配结果（人工可二次选片段）**
  - 全局配置中心
  - 处理进度实时显示
  - 片段预览、替换、重排

# 三、最强亮点：**三级素材匹配机制（你要的精准+可靠）**
## 流程（绝对不会出错）
1. **RAG 初筛**：向量检索 → 取出 TOP12 候选片段
2. **LLM 精筛**：大模型重新排序 → 选出 TOP3~5 最优
3. **人工自选**：前端展示**所有候选片段**，用户手动替换/选择
→ 最终输出 100% 满意的素材片段

## 前端呈现
- 主选片段：蓝色高亮（LLM推荐）
- 备选片段：灰色卡片，**一键替换**
- 用户可任意增删改片段顺序

# 四、视频切分：**双模式自由切换（产品级体验）**
## 模式 A：智能镜头切分（默认）
- PySceneDetect 自动识别镜头切换
- 长短不一，画面更自然
## 模式 B：固定时长切分（强制开关）
- 5s / 10s / 15s 自定义
- 适合无镜头变化的素材（课程、录屏）
## 前端
- 切分模式 → 下拉选择
- 灵敏度/时长参数 → 可配置

# 五、最关键：**全服务抽象化设计（可无限拓展）**
你要求的：**VLM、TTS、ASR、向量库、LLM 全部抽象成接口**
后期随便换模型/服务商，不改业务代码！

## 抽象接口设计（核心拓展性）
```
IVLM
  generate_description(frame_paths) → 描述

ITTS
  synthesize(text) → audio

IASR
  transcribe(audio) → text

IVectorDB
  add_embedding()
  search()

ILLM
  chat()
  rerank()
```

## 支持未来无缝切换
- VLM：OpenAI → 通义 → 本地VLM
- TTS：Edge → OpenAI → 讯飞
- ASR：Whisper → 在线API
- 向量库：SQLite → FAISS → Chroma
**完全不影响主流程**

---

# 六、向量维度：**动态可配置 + 高拓展性**
## 设计
- 向量维度**不写死代码**
- 配置文件：`vector_dimension: 1536 / 1024 / 768`
- SQLite-VSS 支持**任意维度**
- 切换模型/向量维度 → 只需改配置，不用重建表

## 表结构（最终版）
```sql
CREATE VIRTUAL TABLE clip_embeddings USING vss0(
  embedding(vector_dimension)  -- 动态从配置读取
);
```

# 八、完整用户交互流程（最终版）
## 1. 素材入库
- 上传多个视频
- 选择切分模式并处理
- 自动：抽音频 → ASR → 抽帧 → VLM描述 → 向量入库

## 2. 配置（可选）
- 进入设置页改模型、参数、切分模式

## 3. 开始匹配
- 勾选要检索的视频（缩小范围）
- 输入文案 / AI 生成文案
- 执行：
  1. RAG 初筛 12 个片段
  2. LLM 精排 5 个片段
  3. 前端展示：推荐片段 + 所有备选片段

## 4. 人工编辑
- 替换片段
- 增删片段
- 调整顺序
- 预览文案

## 5. 生成配音 & 导出
- TTS 生成配音
- 导出：文案 + 配音 + 片段列表
→ 直接可剪映/PR生成视频
